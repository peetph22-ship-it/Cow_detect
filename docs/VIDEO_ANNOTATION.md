# อัดวิดีโอและจดเวลาเพื่อเทียบกับระบบ (วันที่ 7 ธ.ค.)

ใช้กับ `backend_node/scripts/compare_video.js` ได้ตัวเลขสำหรับเปเปอร์:
ทายท่าถูกกี่ % ต่อภาพ (+ kappa), เวลานอน/ยืน/กินรวมคลาดกี่นาที, จำนวนครั้งที่ลงนอน/ลุกยืน
และ**ความไวต่อรอบถ่ายภาพ** (15/30/60/120/300 วิ) แยกความคลาดจาก "รอบถ่าย" ออกจาก "โมเดลและการติดตาม"

## 1. อัดวิดีโอ

**ทางเลือกที่ดีที่สุด:** ถ้ากล้อง Dahua มีช่อง microSD ให้ตั้งกล้องอัดวิดีโอลงการ์ดทั้งวัน
ได้มุมเดียวกับภาพที่ระบบใช้ และมีเวลาบนภาพจากนาฬิกาของกล้อง (ตั้ง NTP ให้ตรงก่อน)

**ถ้าใช้มือถือ:**
- ตั้งเวลามือถือเป็น "อัตโนมัติ" (ตรงกับเวลาอินเทอร์เน็ต) ก่อนเริ่ม
- ตั้งขาตั้ง ไม่ถือ ให้เห็นวัวเป้าหมายทั้งตัวและรางอาหาร
- **ตอนเริ่มทุกไฟล์:** ถ่ายหน้าจอนาฬิกาที่มีวินาที (เช่น นาฬิกามือถืออีกเครื่อง) ไว้ในเฟรม 3–5 วินาที แล้วจดเวลาเริ่มของไฟล์นั้น
- ถ่ายซ้ำทุก 1 ชม. และทุกครั้งที่หยุด/เริ่มอัดใหม่ (เปลี่ยนแบต, ไฟล์เต็ม)
- จดเหตุการณ์ข้างนอก: เวลาให้อาหาร รีดนม คนเข้าคอก เปิดพัดลม

## 2. จดเวลาจากวิดีโอ

คัดลอก [`templates/video_annotation_template.csv`](templates/video_annotation_template.csv) แล้วจด 1 บรรทัดทุกครั้งที่ท่าเปลี่ยน

| คอลัมน์ | ใส่อะไร |
|---|---|
| `start` | เวลาที่ท่านี้เริ่ม: เวลานาฬิกา `2026-12-07 08:42:10` (แนะนำ) หรือเวลาในวิดีโอ `1:23:45` |
| `behavior` | `lying` / `standing` / `feeding` / `not_visible` / `end` (ใช้ภาษาไทย นอน/ยืน/กิน/ไม่เห็น ได้) |
| `note` | อะไรก็ได้ (ไม่ใช้คำนวณ) |

**นิยามท่า (ต้องตรงกับระบบ):**
- **นอน (lying):** ลำตัวแนบพื้น รวม**นอนกิน**ด้วย
- **ยืน (standing):** ยืนทั้งหมด รวม**ดื่มน้ำ**และเดิน
- **กิน (feeding):** ยืนและหัวลอดราวกั้นอาหาร / ก้มกินที่รางอาหาร
- **ไม่เห็น (not_visible):** มองไม่เห็นวัวเป้าหมาย หรือวิดีโอขาด (ช่วงนี้ไม่นับในการเทียบ)
- แถวสุดท้ายต้องเป็น `end` = เวลาที่หยุดดูวิดีโอ
- ท่าที่สั้นกว่า 10 วินาทีไม่ต้องจด (ระบบถ่ายทุก 15 วิ)

## 3. รันเทียบ

```bash
# CSV ระบบ: farm_detail > การ์ดวัวรายตัว > ส่งออก "รายภาพ" ของวันนั้น
node backend_node/scripts/compare_video.js --system cow_<tag>_2026-12-07_snapshots.csv --video video_2026-12-07.csv --json compare_2026-12-07.json

# ถ้าจดเป็นเวลาในวิดีโอ (1:23:45) ใส่เวลานาฬิกาตอนวิดีโอ 0:00 (ไฟล์ละครั้ง)
node backend_node/scripts/compare_video.js --system ... --video part1.csv --video-start "2026-12-07 08:03:12"
```

ฝึกก่อนวันจริงได้ด้วยหน้า simulator: ส่งออก CSV ของคลิป (คอลัมน์ `t_sec`) แล้วจดเวลาเป็นเวลาในคลิป (`0:00`, `1:23`) ไม่ต้องใส่ `--video-start`
