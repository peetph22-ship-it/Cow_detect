# รายการตรวจหน้างาน — วันดูฟาร์ม (≈ 25 พ.ย. 2569)

> พิมพ์หน้านี้ไปด้วย ติ๊กทีละข้อ ข้อไหนทำไม่ได้ให้จดเหตุผลไว้ข้างๆ

## A. ก่อนออกเดินทาง (เช็กที่บ้าน)

- [ ] **กล่องเซ็นเซอร์ส่งข้อมูลได้:** เสียบไฟ → หน้าแจ้งเตือนของ admin ไม่ขึ้น "ขาดการติดต่อ" ค้าง และ firmware เป็น **1.5.0** (ล่าสุดกล่องรายงาน 1.4.1 ซึ่งไม่รับรอบถ่ายภาพจากหน้าเว็บ ต้องแฟลชใหม่)
- [ ] **Wi-Fi ของ router ตรงกับกล่อง:** ชื่อและรหัส Wi-Fi ของ router = ค่าใน `firmware/cowcare_sensor/secrets.h` (ไม่ต้องแฟลชใหม่) — ถ้าไม่ตรง ให้แฟลชใหม่ด้วยค่าของ router
- [ ] **วงแลนของ router เป็น 192.168.1.x:** กล้อง Dahua ใช้ IP ตายตัว **192.168.1.108** ถ้า router ใช้วงอื่น (เช่น travel router หลายรุ่นใช้ 192.168.8.x) ต้องเปลี่ยนวงของ router หรือเปลี่ยน IP กล้อง ไม่งั้นกล่องดึงภาพไม่ได้
- [ ] **router ออกเน็ตได้:** ซิม 4G / แชร์เน็ตจากมือถือ — ทดสอบที่บ้านก่อน
- [ ] **ซ้อมกล้อง:** ตั้งรอบถ่ายภาพ **60 วินาที** ที่หน้าอุปกรณ์ (admin) + เปิด **เก็บภาพทุกภาพ 1 ชม.** (ปุ่มรูปภาพในแถวกล่อง) แล้วเห็นจำนวนภาพเพิ่มทุกนาที
- [ ] **รันรายงานซ้อม** หลังครบ 1 ชม.: `node backend_node/scripts/rehearsal_report.js --device ESP32-S3-01` → ต้องผ่านทุกข้อ (ภาพเข้าครบ ≥ 95%, ประมวลผล ≤ 40 วิ/ภาพ, server ยุ่ง ≤ 10%) ไม่ผ่าน = ตัดสินเรื่องอัปเกรด Render ก่อนไป
- [ ] **เข้าระบบ admin ได้** จากมือถือและ laptop

**ของที่ต้องเอาไป**

| | |
|---|---|
| ☐ กล่องเซ็นเซอร์ + หัววัด + สาย RS485 | ☐ adapter 12V ของกล่อง |
| ☐ กล้อง Dahua + adapter / PoE injector | ☐ สายแลน (เผื่อยาว 10–20 ม.) |
| ☐ router + ซิม/สายชาร์จ | ☐ ปลั๊กพ่วง (เผื่อยาว) |
| ☐ power bank (จ่ายไฟระหว่างชาร์จได้) | ☐ เคเบิลไทร์ เทปกาว ไขควง |
| ☐ ตลับเมตร | ☐ laptop + ที่ชาร์จ, มือถือ (ถ่ายรูป + แชร์เน็ตสำรอง) |

## B. สำรวจที่ฟาร์ม

**จุดติดกล้อง** (ยึดตามมุมของภาพที่ใช้ฝึกโมเดล: กล้องติดผนัง ก้มประมาณ 17° ภาพแนวนอน 16:9)

| | ✅ ทำแบบนี้ | ❌ เลี่ยง |
|---|---|---|
| ตำแหน่ง | ผนัง/เสา/ขื่อ **ด้านหัวหรือท้ายคอก** มองไปตามแนวยาวของคอก | ติด**กลางเพดานมองตรงลง** (เห็นแต่หลังวัว โมเดลจับได้ ~3 ใน 12 ตัว) |
| ความสูง | **2.5–4 ม.** | สูงเกิน 5 ม. (วัวเล็ก) หรือต่ำกว่า 2 ม. (วัวบังกันเอง/วัวชนกล้อง) |
| มุมก้ม | **15–35°** จากแนวนอน เห็นด้านข้าง+หลังวัว | ก้มเกิน 60° หรือมองตรงลง 90° |
| ภาพ | **แนวนอน** 1920×1080 เลนส์ปกติ (3.6–4 มม.) | ภาพแนวตั้ง, เลนส์ตาปลา/มุมกว้างมาก (ขอบภาพบิด) |
| ระยะถึงวัว | 3–15 ม. วัวแต่ละตัวกว้าง **≥ 1/10 ของภาพ** | วัวไกลจนตัวเล็ก หรือครึ่งตัวอยู่นอกภาพ |
| สิ่งกีดขวาง | ราวกั้นซองนอน**ขนาน**กับแนวมองหรืออยู่ใต้ภาพ | ราว/เสา/สายยาง/พัดลม**พาดทับตัววัว** |
| แสง | หันหลังให้ด้านเปิดของโรงเรือน, กลางคืนใช้ IR | หันเข้าด้านที่แดดส่อง (ย้อนแสง) |
| การยึด | ยึดแน่น ไม่สั่นเวลาพัดลมเปิด | ขาตั้ง/ยึดหลวม (กรอบสั่น การวัดการเดินผิด) |
| วัวเป้าหมาย | ให้ซองนอน+รางอาหารของวัวตัวที่ติดตามอยู่**กลางภาพ** | วัวเป้าหมายอยู่ขอบภาพ |

- ก่อนยึดถาวร: ถ่ายภาพจากมุมนั้น 2–3 ภาพ แล้วลองในหน้า simulator/ภาพล่าสุด ดูว่าโมเดลจับวัวได้ครบไหม ปรับมุมได้ทันทีที่หน้างาน
- [ ] ความสูง ______ ม. (แนะนำ 2.5–4 ม.) มุมก้ม ______° ระยะถึงวัวใกล้สุด/ไกลสุด ______ / ______ ม.
- [ ] เห็นวัวในภาพกี่ตัว ______ วัวแต่ละตัว**กว้างอย่างน้อยประมาณ 1/10 ของภาพ** (วัวตัวเล็ก/ไกลโมเดลพลาดบ่อย)
- [ ] ไม่ย้อนแสง (ดูทิศแดดเช้าและบ่าย) ไม่มีเสา/รั้วบังวัวส่วนใหญ่
- [ ] กลางคืนมีไฟหรือใช้อินฟราเรดของกล้อง

## C. ถ้าลองอุปกรณ์ได้

- [ ] ตั้งรอบถ่ายภาพ 60 วินาที และเปิด **เก็บภาพทุกภาพ 3 ชม.** (ในหน้าต่างเก็บภาพ จำนวนภาพต้องเพิ่มทุกนาที)
- [ ] เก็บภาพจากมุมจริง **≥ 50 ภาพ** หลายช่วงเวลา → ใช้วัดความแม่นยำในคอกไทยครั้งแรก
- [ ] ลองคลิกเลือกวัวเป้าหมาย 1 ตัว (ใส่เบอร์หู) ดูว่าระบบติดตามได้ไหม
- [ ] จดเวลาเริ่ม ______ จบ ______ (ใช้ดึงข้อมูลมาตรวจภายหลัง)
- [ ] กลับถึงบ้าน: ดึงภาพ `node backend_node/scripts/download_collected.js --farm <farm_id>` + รายงานช่วงที่ลอง `rehearsal_report.js --device ESP32-S3-01 --from "2026-11-25 HH:MM" --to "2026-11-25 HH:MM"`

1. ข้อมูลสำหรับ paper: 1 วัน 4–6 ชม. จริงไหม — วันไหน ______ ช่วงเวลาไหน ______
2. ติดตามวัวตัวไหน (เบอร์หู) ______ เลือกด้วยเหตุผลอะไร
3. อนุญาตให้เก็บภาพไปใช้ใน paper และใช้ฝึกโมเดลไหม
4. ติดตั้งค้างไว้ได้ไหม ใครดูแลอุปกรณ์ที่ฟาร์ม

## E. คืนวันที่ 6 ธ.ค. (ระหว่างวันทดสอบกับวันจริง): ดึงภาพ → ตรวจ → ลบ

Supabase แพ็กฟรีมี 1 GB เก็บทุกภาพทุก 15 วิ ประมาณ 430 MB ต่อ 6 ชม. ถ้าไม่ลบภาพวันที่ 6 พื้นที่อาจเต็มกลางวันที่ 7

**ก่อนวันที่ 6 (ทำที่บ้าน ครั้งเดียว):** ใส่ `SUPABASE_URL` และ `SUPABASE_SERVICE_ROLE_KEY` ใน `backend_node/.env` บนโน้ตบุ๊ก
(ค่าเดียวกับ Render > Environment, ห้าม commit) แล้วลองรันคำสั่งข้อ 1 กับวันที่ซ้อม

1. [ ] หยุดโหมดเก็บทุกภาพ (Admin > อุปกรณ์) หรือรอให้หมดเวลาเอง
2. [ ] ดึงภาพลงเครื่อง (รันซ้ำได้ ดึงต่อจากที่ค้าง):
   `node backend_node/scripts/download_collected.js --farm <farm_id> --date 2026-12-06`
3. [ ] คัดลอกโฟลเดอร์ `backend/training_archive/farm_collect/<farm_id>/2026-12-06/` ไปที่ที่ 2 (Google Drive หรือ external drive)
4. [ ] ตรวจอย่างเดียวก่อน (ไม่ลบ): ทุกไฟล์บน Storage ต้องมีสำเนาตรงทั้ง 2 ที่
   `node backend_node/scripts/free_collected.js --farm <farm_id> --date 2026-12-06 --backup <โฟลเดอร์ที่ 2>`
   ต้องขึ้น `มีปัญหา 0` (ถ้าไม่ใช่ 0 ให้รันข้อ 2–3 ซ้ำ)
5. [ ] ลบจริง (ต้องพิมพ์ `2026-12-06` ยืนยัน, ถ้ามีปัญหาแม้ไฟล์เดียวสคริปต์จะไม่ลบอะไรเลย):
   `node backend_node/scripts/free_collected.js --farm <farm_id> --date 2026-12-06 --backup <โฟลเดอร์ที่ 2> --delete`
6. [ ] เปิดโหมดเก็บทุกภาพใหม่สำหรับวันที่ 7 (หน้าอุปกรณ์จะแสดงพื้นที่ Storage ที่เหลือ)

สคริปต์ลบเฉพาะ `collect/<farm>/<วันที่>/` ไม่แตะภาพรายชั่วโมงหรือภาพล่าสุด และลบเฉพาะไฟล์ที่ตรวจแล้วตอนรัน
