# รายการตรวจหน้างาน — วันดูฟาร์ม (≈ 25 พ.ย. 2569)

> พิมพ์หน้านี้ไปด้วย ติ๊กทีละข้อ ข้อไหนทำไม่ได้ให้จดเหตุผลไว้ข้างๆ

## A. ก่อนออกเดินทาง (เช็กที่บ้าน)

- [ ] **กล่องเซ็นเซอร์ส่งข้อมูลได้:** เสียบไฟ → หน้าแจ้งเตือนของ admin ไม่ขึ้น "ขาดการติดต่อ" ค้าง และ firmware เป็น **1.5.0**
- [ ] **Wi-Fi ของ router ตรงกับกล่อง:** ชื่อและรหัส Wi-Fi ของ router = ค่าใน `firmware/cowcare_sensor/secrets.h` (ไม่ต้องแฟลชใหม่) — ถ้าไม่ตรง ให้แฟลชใหม่ด้วยค่าของ router
- [ ] **วงแลนของ router เป็น 192.168.1.x:** กล้อง Dahua ใช้ IP ตายตัว **192.168.1.108** ถ้า router ใช้วงอื่น (เช่น travel router หลายรุ่นใช้ 192.168.8.x) ต้องเปลี่ยนวงของ router หรือเปลี่ยน IP กล้อง ไม่งั้นกล่องดึงภาพไม่ได้
- [ ] **router ออกเน็ตได้:** ซิม 4G / แชร์เน็ตจากมือถือ — ทดสอบที่บ้านก่อน
- [ ] **ซ้อมกล้อง:** ตั้งรอบถ่ายภาพ **60 วินาที** ที่หน้าอุปกรณ์ (admin) แล้วเห็นภาพเข้าทุกนาทีอย่างน้อย 1 ชม.
- [ ] **เข้าระบบ admin ได้** จากมือถือและ laptop

**ของที่ต้องเอาไป**

| | |
|---|---|
| ☐ กล่องเซ็นเซอร์ + หัววัด + สาย RS485 | ☐ adapter 12V ของกล่อง |
| ☐ กล้อง Dahua + adapter / PoE injector | ☐ สายแลน (เผื่อยาว 10–20 ม.) |
| ☐ router + ซิม/สายชาร์จ | ☐ ปลั๊กพ่วง (เผื่อยาว) |
| ☐ power bank (จ่ายไฟระหว่างชาร์จได้) | ☐ เคเบิลไทร์ เทปกาว ไขควง |
| ☐ ตลับเมตร | ☐ laptop + ที่ชาร์จ, มือถือ (ถ่ายรูป + แชร์เน็ตสำรอง) |

## C. ถ้าลองอุปกรณ์ได้

- [ ] ตั้งรอบถ่ายภาพ 60 วินาที (และเปิดโหมดเก็บภาพทุกภาพ ถ้าพร้อมแล้ว)
- [ ] เก็บภาพจากมุมจริง **≥ 50 ภาพ** หลายช่วงเวลา → ใช้วัดความแม่นยำในคอกไทยครั้งแรก
- [ ] ลองคลิกเลือกวัวเป้าหมาย 1 ตัว (ใส่เบอร์หู) ดูว่าระบบติดตามได้ไหม
