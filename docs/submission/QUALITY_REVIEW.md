## การเพิ่มภาพแอดมิน

เจ้าของอนุญาตให้เข้าสู่ระบบเพื่อบันทึกภาพ ใช้เฉพาะ Dashboard และหน้าอุปกรณ์ที่กรองเซ็นเซอร์ บันทึกภาพสรุป กราฟรายวัน/พยากรณ์ และตารางสถานะกล่อง ไม่มีการกดบันทึก แก้ไข ลบ รันสรุป หรือเปิดสตรีมกล้อง การเข้าสู่ระบบอาจบันทึกเวลา login ล่าสุดตามพฤติกรรมปกติของระบบ

ตรวจภาพที่บันทึกแล้วไม่พบรหัสผ่าน ชื่อบัญชี อีเมลบัญชี หรือ IP กล้องในพื้นที่ภาพ ไม่มีการเก็บข้อมูลเข้าสู่ระบบไว้ในไฟล์ชุดส่ง ภาพเป็นส่วนของหน้าจอที่ระบบแสดงจริง ไม่ได้สร้างข้อมูลจำลองแทนภาพแอดมิน

## ข้อจำกัดของการตรวจ

- เป้าต้นทุนในฉบับส่งยังไม่ใช่ใบรายการอุปกรณ์หรือราคาซื้อที่ยืนยัน ส่วนการเงินภายในเป็นร่างสมมติฐานเดิม ค่าบริการพยากรณ์เชิงพาณิชย์และสิทธิ์โมเดลยังต้องยืนยันก่อนเปิดขาย งานนี้ไม่ได้ซื้อบริการหรือเปลี่ยน endpoint ระบบจริง
- เปิดเว็บไซต์จริงผ่าน HTTPS และตรวจภาพแอดมินที่บันทึกเพิ่มแล้ว ส่วน HTMLชุดส่งยังไม่ได้ตรวจภาพในเบราว์เซอร์ เนื่องจาก browser tool เคยปฏิเสธการเปิด file:// ตามนโยบาย จึงตรวจ source, โครงสร้าง, สคริปต์ และข้อมูลภาพในเครื่องเป็นทางเลือก ไม่อ้อมข้อจำกัดด้วยช่องทางอื่น
- ต้องเปิด HTML บนคอมพิวเตอร์และมือถือจริงอีกครั้ง โดยเฉพาะการตัดบรรทัด ตาราง ภาพ และการพิมพ์ก่อนส่ง
- ไม่ได้รัน backtest354วันซ้ำ ไม่ได้วัดความแม่นฟาร์มจริง ไม่ตรวจ production configuration หรือทดลองวินิจฉัยโรค
- ไม่ได้ทดสอบการอัปโหลดจริง ขนาดไฟล์สูงสุด วิธีนับคำไทย และข้อกำหนด Gen AI/AWS เฉพาะรอบต้องตรวจจากผู้จัด

การตรวจเอกสารไม่ใช่การรับรองทางสัตวแพทย์หรือการยืนยันผ่านเกณฑ์การแข่งขัน งานนี้ไม่ได้อัปโหลด ส่งผลงาน หรือยืนยันคุณสมบัติสมาชิกแทนเจ้าของ
