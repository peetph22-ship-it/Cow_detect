# CowCare AI — ชุดส่งหลักสำหรับรอบเสนอแนวคิด

ใช้ไฟล์ในโฟลเดอร์นี้เป็นฉบับหลักที่รวมเนื้อหาปรับปรุงและภาพหน้าจอจากระบบทดสอบแล้ว:

- [CowCare_AI.md](CowCare_AI.md): แนวคิด ทฤษฎี สถานะต้นแบบ ขอบเขต AI แผนประเมิน และหัวข้อ 7 “ต้นทุนเป้าหมายและแนวทางการเข้าถึง”
- [CowCare_AI.html](CowCare_AI.html): เนื้อหาเดียวกับ Markdown พร้อมภาพหน้าจอจริงและสถานการณ์สมมติที่ติดป้าย
- [description.txt](description.txt): คำอธิบายสั้นสำหรับฟอร์ม
- [QUALITY_REVIEW.md](QUALITY_REVIEW.md): ผลตรวจและสิ่งที่ยังต้องตรวจโดยเจ้าของ

ส่งทั้ง `.md` และ `.html` ตามคำแนะนำอาจารย์ที่ปรึกษา โฟลเดอร์ `revised-2026-10-26/` เป็นฉบับก่อนรวม ไม่ใช่ชุดส่งหลัก

## แผนภายใน

[BUSINESS_PLAN.md](BUSINESS_PLAN.md) เก็บร่างการเงินเดิม ตารางกำไร และจุดคุ้มทุนไว้สำหรับทบทวนภายใน พร้อมหมายเหตุว่าสมมติฐานเดิมต้องปรับตามเป้าต้นทุนล่าสุด ไม่รวมไฟล์นี้ในชุดที่แนะนำให้อัปโหลด และ HTML ไม่อ่านหรือเชื่อมไปยังไฟล์นี้ เครื่องมือสร้าง HTML จะไม่เขียนทับแผนภายใน

## HTML ที่ใช้อัปโหลด

ในช่องอัปโหลด HTML เลือก `CowCare_AI.html` เพียงไฟล์เดียว เนื้อหาทุกหัวข้อ ภาพทั้ง 6 ภาพ รูปแบบ และปุ่มสาธิตรวมอยู่ภายในแล้ว ไม่ต้องแนบโฟลเดอร์ `assets/`, เครื่องมือสร้าง, Markdown หรือ ZIP เพื่อเปิดอ่าน HTML เมนูสารบัญเป็นการเลื่อนไปยังหัวข้อในหน้าเดียว ไม่ได้เปิดเอกสารอีกไฟล์ ส่วน Markdown ใช้สำหรับช่องส่ง `.md` แยกตามที่ฟอร์มกำหนด

อ่านเนื้อหา ดูภาพ และกดปุ่มสาธิตใน HTML ได้โดยไม่ใช้อินเทอร์เน็ต มีเพียงลิงก์ไปยังเว็บไซต์จริงและเอกสารอ้างอิงภายนอกที่ต้องใช้อินเทอร์เน็ต

## ขอบเขตที่ยึดถือ

แนวคิดหลักคือสนับสนุนการติดตามสุขภาพฝูงโคนมผ่านความเสี่ยงจากความร้อน ข้อมูลปัจจุบันเป็นสิ่งแวดล้อมและท่าทางบางส่วน แผน AI เน้นแอดมินวิเคราะห์ข้อมูลและสัตวแพทย์ใช้ข้อมูลประกอบการตรวจประเมินโรค โดยสัตวแพทย์เป็นผู้ตรวจและสรุปผล

สถานะพร้อมสำหรับการติดตั้งเพื่อรวบรวมข้อมูล โดยยังไม่กำหนดวันติดตั้ง สหกรณ์เป็นทางเลือกที่ต้องหารือและยืนยันความร่วมมือก่อน

หัวข้อด้านต้นทุนในฉบับส่งใช้เป้าสำหรับรุ่นถัดไป: ชุดเซ็นเซอร์ไม่เกิน 1,000 บาท กล้องเสริมประมาณ 2,000 บาท หรืออุปกรณ์รวมประมาณ 3,000 บาท เป็นเป้าออกแบบที่ต้องยืนยันด้วยรายการอุปกรณ์จริง ยังไม่รวมค่าแรง ติดตั้ง เดินทาง ระบบออนไลน์ อินเทอร์เน็ต การดูแล และกำไร เริ่มใช้เซ็นเซอร์ก่อน เพิ่มกล้องตามความจำเป็น และศึกษาค่าบริการรายปีภายหลัง โดยไม่กำหนดราคาขาย กำไร หรือจุดคุ้มทุนในไฟล์ส่ง

## การแก้ไขครั้งถัดไป

1. แก้เนื้อหาหลักที่ `CowCare_AI.md` และคำอธิบายที่ `description.txt`
2. สร้าง HTML ใหม่ด้วย `node docs/submission/tools/build_submission.mjs` จาก root ของโปรเจกต์ เนื้อหาต้นทุนในฉบับส่งแก้ที่ Markdown หลัก ส่วนแผนภายในดูแลแยกที่ `BUSINESS_PLAN.md`
3. ตรวจเนื้อหาและ HTML บนคอมพิวเตอร์/มือถือ โดยเฉพาะตาราง ปุ่ม และภาพจริงก่อนส่ง

ตัวสร้าง HTML ใช้แพ็กเกจ `marked` ที่ติดตั้งในเครื่องหรือ runtime ที่มีอยู่ หากหาไม่พบให้ตั้ง `COWCARE_MARKED_MODULE` ชี้ไปยัง module ที่ติดตั้งแล้ว ขั้นตอนนี้จำเป็นเฉพาะเมื่อสร้างไฟล์ใหม่ ผู้เปิด HTML ที่สร้างเสร็จแล้วไม่ต้องติดตั้งเครื่องมือ

รูปหน้าจอเกษตรกรสามรูปและแอดมินสามรูปอยู่ใน `assets/` และถูกฝังเป็นข้อมูลใน HTML แล้ว จึงไม่ต้องแนบโฟลเดอร์ assets เพิ่มเพื่ออ่าน HTML ภาพแอดมินแสดงภาพรวม กราฟ THI/พยากรณ์ และสถานะเซ็นเซอร์ โดยตัดข้อมูลบัญชีและการตั้งค่ากล้องออก ส่วนลิงก์อ้างอิงและเว็บจริงต้องใช้อินเทอร์เน็ต หน้าเกษตรกร/แอดมินของเว็บจริงต้องเข้าสู่ระบบ

ก่อนส่งให้เจ้าของตรวจข้อมูลทีม คุณสมบัติผู้สมัคร เงื่อนไข Gen AI/AWS แม่แบบ ขนาดไฟล์ และเวลาปิดจากผู้จัดอีกครั้ง ชุดนี้ไม่ได้ยืนยันแทนผู้จัดว่าเงื่อนไขเหล่านั้นผ่านครบแล้ว
