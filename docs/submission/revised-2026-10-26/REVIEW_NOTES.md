## ผลทบทวน

ตรวจแยกสามด้าน: วิชาการ/ทฤษฎี, ความตรงกับโค้ด, และกลยุทธ์เนื้อหากับ UX ก่อนรวมผลและแก้ต้นฉบับ

แก้ประเด็นหลัก: ขอบเขตติดตามสุขภาพผ่านความเสี่ยงสิ่งแวดล้อม, ชื่อสัดส่วนท่านอนแทน CCI มาตรฐาน, ไม่ยืนยันการฟื้นตัว, แยกงานวิจัยรายวันกับเกณฑ์ต้นแบบระยะสั้น, ไม่อนุมาน sensor drift จากท่านอน, อธิบาย mean ในผลประเมินเดิมกับ median ใน runtime, ไม่รับรองระยะคิว/การบังคับ key ที่ยังไม่ทดสอบ, และแยก Gen AI/LINE ที่ยังเป็นแผน

แก้ตามเจ้าของล่าสุด: เปลี่ยนแผน AI เป็นช่วยแอดมินวิเคราะห์ข้อมูลและช่วยสัตวแพทย์จัดข้อมูลประกอบการตรวจประเมินโรค; ไม่ระบุวันติดตั้งหรือผูกหลักฐานรอบแนวคิดกับผลฟาร์ม; สหกรณ์เป็นเพียงทางเลือกที่ต้องตกลงความร่วมมือและสิทธิ์ข้อมูลก่อน

รอบตรวจสุดท้ายแก้ข้อความจำนวนภาพ audit: ระบบคำนวณ metrics จากภาพที่ตรวจแล้วได้ก่อน 30 ภาพ ส่วน 30 เป็นเกณฑ์เตือนความเพียงพอเบื้องต้นในการวิเคราะห์เชิงสำรวจ ไม่ใช่ใบรับรองความแม่นยำ

## ตรวจที่ผ่าน

- เนื้อหาหลักใน HTML ตรงกับ Markdown ฉบับเดียวกัน
- HTML JavaScript ผ่าน syntax check และตรวจ logic แบบจำลองของ 4 ปุ่ม; ข้อมูลเก่ายังคงบอกว่าเป็นค่าครั้งก่อน หัววัดขัดข้องล้างค่า THI
- ไม่มี script/font/image ที่ต้องโหลดจากภายนอกเพื่ออ่านเนื้อหาและใช้แผงสาธิต
- HTML id 24 รายการไม่ซ้ำ และลิงก์ภายใน 13 รายการชี้ได้ครบ
- คำอธิบายสั้นอยู่ต่ำกว่า 100 คำเมื่อแบ่ง word-like segments ด้วย ICU ภาษาไทย และ 14 ส่วนเมื่อแยกด้วยช่องว่าง
- วันที่ภายในชุดส่งใช้เป้าหมายส่ง 2 พ.ย. และสำรอง 3 พ.ย. ก่อนกำหนด 4 พ.ย.
- ไม่เปลี่ยน source code ระบบฟาร์มหรือฐานข้อมูล ไม่เรียกโมเดลจริง ไม่อัปโหลดหรือส่งผลงาน

## ยังไม่ได้ตรวจและสิ่งที่ต้องทำต่อ

- ยังไม่ได้ตรวจภาพและ interaction ในเบราว์เซอร์จริง: browser tool ปฏิเสธ file:// ตามนโยบายที่อนุญาตเฉพาะ http/https จึงใช้การตรวจ source/โครงสร้างและ logic แบบจำลองเป็นทางเลือก ไม่อ้อมข้อจำกัดด้วยการเปิดผ่านช่องทางอื่น
- ต้องเปิด HTML บนมือถือและคอมพิวเตอร์จริง ตรวจการตัดบรรทัด ตาราง ปุ่ม และการพิมพ์ก่อนส่ง
- ไม่ได้วัด field accuracy หรือผลสุขภาพสัตว์ ไม่ได้รัน backtest ชุดใหญ่ใหม่ ไม่ได้ยืนยัน configuration production
- ต้องยืนยันข้อกำหนด Gen AI/AWS ขนาดไฟล์ แม่แบบ และเวลาปิดจากผู้จัด หากมีคู่มือเฉพาะรอบให้ยึดประกอบ
- หากมีผลติดตั้งใหม่ ให้แก้ Markdown แล้วสร้าง HTML ใหม่เพื่อให้เนื้อหาตรงกัน ห้ามเพิ่มผลภาคสนามที่ยังไม่ได้วัด
