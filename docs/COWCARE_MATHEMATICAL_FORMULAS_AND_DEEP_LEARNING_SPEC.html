📄 Official System Specification (อัปเดต 24 ต.ค. 2026)

CowCare AI — คู่มือสูตรการคำนวณและสถาปัตยกรรมโมเดล AI

ระบบเฝ้าระวังและวิเคราะห์ความเครียดจากความร้อนในโคนมไทยด้วย IoT (SHT20 RS485) & YOLO26m ONNX

📌 1. บทนำและภาพรวมระบบ

ระบบ CowCare AI ออกแบบมาเพื่อเฝ้าระวังความเครียดจากความร้อน (Heat Stress) ในโคนมลูกผสมไทย โดยผสานการทำงาน 3 ส่วนหลักที่ตรวจสอบที่มาได้จริงทั้งหมด:

  • IoT Telemetry (Firmware v1.4.1): กล่องเซ็นเซอร์ ESP32-S3 อ่านค่าจากหัววัด RS485 ตระกูล XY-MD02 ชิป SHT20 ($\pm 0.3^\circ\text{C} / \pm 3\%\text{ RH}$) ส่งผ่าน HTTPS (Root CA + X-Device-Key) พร้อมคิวสำรองข้อมูลในบอร์ดเมื่อเน็ตหลุด และรายงานสถานะกล่องทุก 5 นาที
  • Unified Heat Metrics (5-Minute Buckets): คำนวณค่า THI ด้วยสูตรมาตรฐาน NRC (1971) และเกณฑ์โคนมลูกผสมไทย 74 / 76 / 82 ชุดเดียวกันทั้งระบบ
  • 3-Day Hybrid Forecast & Outdoor Comparison (forecastService.js, outdoorWeather.js): พยากรณ์ THI เฉลี่ยรายวันล่วงหน้า 3 วันด้วยข้อมูล Open-Meteo ECMWF (ecmwf_ifs025) หักลบค่าเพี้ยนมัธยฐานจากเซ็นเซอร์ฟาร์มย้อนหลัง 3–14 วัน และเปรียบเทียบอากาศในโรงเรือนกับภายนอกย้อนหลัง 72 ชม. ช่วงบ่าย 12:00–16:59 น.
  • Computer Vision (YOLO26m ONNX): บอร์ดดึงภาพจากกล้อง Dahua DH-IPC-HFW2231TP-ZAS-S2 ทุก 10 นาที ส่งให้เซิร์ฟเวอร์รันโมเดล YOLO26m ONNX บน Worker Thread นับวัวแยกตาม 4 ท่า (drinking / feeding / lying down / standing)

🧮 2. สูตรการคำนวณทางคณิตศาสตร์และเกณฑ์โคนมลูกผสมไทย

2.1 สูตรดัชนีอุณหภูมิและความชื้นมาตรฐาน (NRC, 1971)

ใช้สมการมาตรฐาน NRC (1971) ตัวเดียวกับที่งานวิจัยโคนมไทยใช้ (Sae-tiao et al., 2019) ทั้งระบบ:

$$\text{THI} = (1.8 \times T + 32) - (0.55 - 0.0055 \times \text{RH}) \times (1.8 \times T - 26)$$
โดย $T$ คือ อุณหภูมิในโรงเรือน ($^\circ\text{C}$) และ $\text{RH}$ คือ ความชื้นสัมพัทธ์ ($\%$) จากสเปกของชิป SHT20 ($\pm 0.3^\circ\text{C} / \pm 3\%\text{ RH}$) ค่า THI มีความคลาดเคลื่อนตามสเปกประมาณ $\pm 0.7$

2.2 เกณฑ์ระดับความเครียดความร้อนสำหรับโคนมลูกผสมไทย (Boonkum et al., 2011; 2024)

ระดับความเสี่ยง เกณฑ์โคนมลูกผสมไทยทั่วไป เกณฑ์ฝูงสายเลือด HF สูง (≥87.5%) ความหมายและงานวิจัยอ้างอิง สถานะ
ปกติ (Normal) $\text{THI} < 74$ $\text{THI} < 72$ สภาวะปกติ โคพักผ่อนและระบายความร้อนได้ตามปกติ ปกติ
เฝ้าระวัง (Mild) $74 \le \text{THI} < 76$ $72 \le \text{THI} < 74$ จุดที่น้ำนมเริ่มลดในแม่โคท้อง 3+ สายเลือด HF ≥ 87.5% (Boonkum et al., 2011) เฝ้าระวัง
เครียดจากความร้อน (Moderate) $76 \le \text{THI} < 82$ $74 \le \text{THI} < 80$ จุดเริ่มเครียดระดับประชากรโคนมลูกผสมไทย น้ำนมและอัตราผสมติดเริ่มลดลง (Boonkum et al., 2024) เครียด
วิกฤต (Severe) $\text{THI} \ge 82$ $\text{THI} \ge 80$ ผลผลิตน้ำนมลดลงเร็วขึ้นชัดเจน ต้องเร่งระบายความร้อนทันที (Boonkum et al., 2011) วิกฤต

2.3 ตัวชี้วัดรายวันและรายชั่วโมงแบบแบ่งถังเวลา 5 นาที (heatMetrics.js)

เฉลี่ยค่าเซ็นเซอร์ทุก 5 นาที ($\Delta t = \frac{5}{60}\text{ ชม.}$) โดยไม่เดาค่าในช่วงที่ไม่มีข้อมูล:

$$\text{Data Hours} = N_{\text{buckets}} \times \frac{5}{60}, \qquad \text{Coverage (\%)} = \min\left(100,\; \text{round}\left(\frac{\text{Data Hours}}{\text{Window Hours}} \times 100\right)\right)$$
$$\text{Stress Hours} = N_{\text{THI} \ge 76} \times \frac{5}{60}, \qquad \text{Night Relief Hours (22:00–06:00)} = N_{\text{night}(\text{THI} < 74)} \times \frac{5}{60}$$
• ระดับความเครียดรายวัน: ประเมินจากค่าเฉลี่ย THI ทั้งวัน เพื่อเทียบตามวิธีของงานวิจัย
• จำนวนวันเครียดติดต่อกัน (stressStreak): นับจำนวนวันล่าสุดที่ THI เฉลี่ยรายวัน $\ge 76$ ติดต่อกัน (เฉพาะวันที่มีข้อมูลอย่างน้อย 12 ชม.)

2.4 ระบบพยากรณ์ THI ล่วงหน้า 3 วัน และการปรับค่าเพี้ยนจากเซ็นเซอร์ฟาร์ม (forecastService.js)

พยากรณ์ THI เฉลี่ยรายวันล่วงหน้า $k \in \{1, 2, 3\}$ วัน ด้วยค่าจาก Open-Meteo ECMWF (ecmwf_ifs025) หักลบค่าเพี้ยนมัธยฐานที่เรียนรู้จากเซ็นเซอร์จริงของฟาร์มในช่วง 3–14 วันล่าสุด (hybrid-ecmwf-bias-v1):

$$\text{bias}_k = \text{clamp}\!\left(\text{median}_{t \in D_{\text{valid}}}\!\left(\widehat{\text{THI}}_{\text{ECMWF}, t}^{(k)} - \overline{\text{THI}}_{\text{farm}, t}\right),\; -6,\; +6\right), \qquad \widehat{\text{THI}}_{\text{pred}}(d+k) = \widehat{\text{THI}}_{\text{ECMWF}}(d+k) - \text{bias}_k$$
• เงื่อนไขวันที่มีข้อมูลครบ ($D_{\text{valid}}$): ใช้เฉพาะวันที่ข้อมูลครบ $\ge 20$ ชม., แต่ละชั่วโมงมีข้อมูล $\ge 60$ จุด และช่วงกลางวัน 10:00–17:00 น. ขาดไม่เกิน 1 ชม.
• กรณีฟาร์มมีข้อมูลไม่ถึง 3 วัน: หากใช้ ECMWF ในจังหวัดภาคเหนือ ใช้ค่าเพี้ยนภูมิภาคเชียงใหม่ ($-1.41 / -1.37 / -1.32$) และหากไม่มีพิกัดหรือเรียก API ไม่ได้ จะถอยกลับไปใช้ค่าเฉลี่ย 72 ชม. ย้อนหลัง (baseline_72h_mean)
• ช่วงร้อนและช่วงเย็นเฉพาะฟาร์ม: คำนวณช่วงร้อนที่สุด (4 ชม.) และช่วงเย็นที่สุดสำหรับให้อาหาร (3 ชม. ระหว่าง 04:00–20:00 น.) จากข้อมูล 72 ชม. ของโรงเรือนนั้นเอง
• กฎความชื้น $\text{RH} \ge 75\%$: แนะนำให้ งดพ่นหมอกฝอย และใช้การฉีดน้ำราดตัววัวช่วงสั้นๆ ร่วมกับเปิดพัดลมแทน
• ข้อควรทราบ: ยังไม่ประเมินปริมาณน้ำนมที่ลดลงเป็นกิโลกรัม เนื่องจากระบบไม่มีข้อมูลบันทึกน้ำนมจริง

🧠 3. สถาปัตยกรรมระบบกล้องและระบบพยากรณ์ในระบบ

🎥 1. ระบบนับท่าวัวจากกล้อง (YOLO26m ONNX)

โมเดล: YOLO26m ONNX (best.onnx บน Node.js Worker Thread)

การเก็บโมเดล: Supabase Private Storage (ตรวจไฟล์ด้วย SHA-256)

  • บอร์ด ESP32-S3 ดึงภาพจากกล้อง Dahua ทุก 10 นาทีผ่าน HTTP Digest (ไม่มีระบบติดตามตัววัวและไม่ตรวจจับท่าหอบ)
  • จำแนกและนับวัวแยกตาม 4 ท่าทาง: ดื่มน้ำ (drinking), กินอาหาร (feeding), นอน (lying down), ยืน (standing)
  • ตัดกรอบซ้อนโดยไม่ดูท่า (Class-Agnostic NMS, conf = 0.25, IoU = 0.70): บังคับ 1 ตัว = 1 กรอบ แก้ปัญหานับวัวซ้ำ
  • ผลทดสอบกับชุดภาพ 203 ภาพ: วัวที่ถูกนับซ้ำลดจาก 11 คู่ เหลือ 0, จำนวนวัวนอนคลาดเฉลี่ย 0.47 ตัว/ภาพ, พลาดวัวประมาณ 21% (เทรนจากภาพต่างประเทศ)
  • เก็บภาพตัวอย่างชั่วโมงละ 1 รูป พร้อมไฟล์ JSON เพื่อใช้นับเทียบและทำ Dataset โรงเรือนไทย

📈 2. ระบบพยากรณ์ 3 วัน (ECMWF + Farm Sensor Bias)

โมเดลที่เปิดใช้งานจริง: hybrid-ecmwf-bias-v1 (forecastService.js)

สถานะโมเดล LSTM/GRU: ปิดไว้ (ทดสอบแล้วแพ้วิธีปัจจุบัน)

  • ผลทดสอบย้อนหลังกับสถานีสนามบินเชียงใหม่ (WMO 48327) 354 วัน (19 ธ.ค. 2024 – 7 ธ.ค. 2025) ค่า MAE (+1/+2/+3 วัน):
  • ค่าเฉลี่ย 72 ชม. ย้อนหลัง: 1.10 / 1.38 / 1.56
  • ECMWF ดิบ: 1.34 / 1.32 / 1.35
  • ECMWF + ปรับค่าเพี้ยน 14 วัน: 0.69 / 0.78 / 0.88 (ระดับความเสี่ยงตรง 94% / 93% / 92%)
  • ECMWF + ปรับค่าเพี้ยน 3 วัน: 0.80 / 0.92 / 1.07
  • GRU (1,212 พารามิเตอร์): 0.88 / 0.91 / 0.91 (ไม่เปิดใช้)
  • เป็นผลวัดกับสถานีตรวจอากาศกลางแจ้ง ต้องวัดซ้ำกับข้อมูลในโรงเรือนจริงหลังติดตั้ง 2 สัปดาห์
