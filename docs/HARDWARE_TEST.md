# ทดสอบความทนทานที่บ้าน 24 ชม. (30 พ.ย.–3 ธ.ค.)

ได้ตัวเลขฮาร์ดแวร์ชุดแรกสำหรับเปเปอร์ และเป็นด่าน "ไป/ไม่ไป" ก่อนวันที่ 6 ธ.ค. (แผน: `docs/PROJECT_PLAN.md` ระยะ 3)

## ก่อนเริ่ม
- [ ] firmware 1.6.0 แฟลชแล้ว Serial ขึ้น `[SENSOR] found ...` (จดรุ่นที่ตรวจเจอ)
- [ ] ต่อผ่าน**เราเตอร์ 4G ที่จะใช้ที่ฟาร์มจริง** (ไม่ใช่ Wi-Fi บ้าน) · หน้าอุปกรณ์ตั้งรอบ 15 วิ · เปิดเก็บทุกภาพ (ไม่จำเป็นทั้ง 24 ชม. เปิด 1–2 ชม. พอ)
- [ ] วางเครื่องอ้างอิง**ข้าง SHT40 ห่างไม่เกิน 10 ซม.** ระดับเดียวกัน ไม่โดนแดดหรือลมพัดลมตรง ๆ จดรุ่นและสเปกความแม่นของเครื่องอ้างอิง
- [ ] เสียบกล่องผ่านมิเตอร์วัดไฟ USB
- [ ] คัดลอก `docs/templates/reference_readings_template.csv` ไว้จดค่าอ้างอิง

## ระหว่าง 24 ชม.
**ค่าอ้างอิง:** จดทุก 30–60 นาที (เวลาไทย `YYYY-MM-DD HH:MM` + อุณหภูมิ + ความชื้น) ช่วงที่อุณหภูมิเปลี่ยนเร็ว (บ่าย/หัวค่ำ) จดถี่ขึ้น
ถ้าเครื่องอ้างอิงบันทึกค่าเองได้ ให้ export แล้วจัดเป็นคอลัมน์เดียวกับแบบฟอร์ม

**ไฟ:** จดค่าวัตต์ตอนปกติ และตอนกล่องส่งภาพ (ค่าจะกระโดดทุก 15 วิ) อย่างละหลายครั้ง และพลังงานสะสม (Wh) ตอนจบ ถ้ามิเตอร์แสดงได้

**ทดสอบความผิดพลาด** (ทำห่างกันอย่างน้อย 30 นาที จดเวลาเริ่ม/จบทุกครั้ง):

| ทดสอบ | ทำอะไร | ที่ควรเกิด |
|---|---|---|
| เน็ตหลุด | ปิดเราเตอร์ 4G 10 นาที แล้วเปิด | ค่าเซ็นเซอร์ไม่หาย (ส่งย้อนหลังจากคิว), กล่องกลับมาเอง |
| เน็ตค้างนาน | ปิดเราเตอร์ 35 นาที | ครบ 30 นาทีกล่องรีบูตเอง (`reset_reason: software`) แล้วกลับมาส่งต่อ |
| ไฟดับ | ดึงปลั๊กกล่อง 2 นาที | heartbeat แรกหลังเสียบบอก `power_on`, ค่าในคิวบน flash ไม่หาย |
| กล้องหลุด | ถอดสาย LAN กล้อง 5 นาที | ภาพขาดช่วงนั้น ค่าเซ็นเซอร์ไม่สะดุด กล้องกลับมาเอง |
| server รีสตาร์ต | Render > Restart service | กล่องรอแล้วส่งต่อ ไม่มีค่าหาย |

## หลังจบ (ใช้ hotspot มือถือ)
```bash
# ตัวเลขฮาร์ดแวร์ทั้งช่วง
node backend_node/scripts/hardware_report.js --device ESP32-S3-01 --from "2026-11-30 09:00" --to "2026-12-01 09:00" --json hw_home_24h.json

# ความแม่นเซ็นเซอร์เทียบเครื่องอ้างอิง
node backend_node/scripts/compare_sensor.js --device ESP32-S3-01 --reference reference_2026-11-30.csv --json sensor_home_24h.json

# ช่วงที่เปิดเก็บทุกภาพ: ภาพครบ / server ยุ่ง / เวลาประมวลผล
node backend_node/scripts/rehearsal_report.js --device ESP32-S3-01 --from "2026-11-30 10:00" --to "2026-11-30 12:00"
```

**คำนวณไฟ:** วัตต์เฉลี่ย × 24 ÷ 1000 = kWh/วัน · × 30 = kWh/เดือน · × อัตราค่าไฟจากบิลจริง = ค่าไฟ/เดือน

## เกณฑ์ไป/ไม่ไป
- [ ] ความพร้อมใช้งาน ≥ 99% **นอกช่วงทดสอบความผิดพลาด**
- [ ] ค่าเซ็นเซอร์ครบ ≥ 95% และค่าที่ค้างในคิวส่งครบหลังเน็ตกลับมา
- [ ] กลับมาเองทุกการทดสอบ (ไม่ต้องกดปุ่มหรือถอดเสียบ)
- [ ] ภาพครบ ≥ 95% และ server ยุ่ง ≤ 10% ที่รอบ 15 วิ (ไม่ผ่าน → ใช้ 30 วิ)
- [ ] ความคลาดเซ็นเซอร์อยู่ในระดับที่ยอมรับได้เมื่อเทียบสเปกของทั้งสองเครื่อง (ถ้า bias ชัด ให้จดไว้ใช้แก้ค่า/รายงานในเปเปอร์)

เก็บไฟล์ `hw_home_24h.json`, `sensor_home_24h.json`, ไฟล์ค่าอ้างอิง และตารางเวลาทดสอบไว้ด้วยกัน (เป็นหลักฐานในเปเปอร์)
