## 📌 1. ที่มาและความสำคัญของโครงการ (Problem & Solution Overview)
เกษตรกรผู้เลี้ยงโคนมในประเทศไทยส่วนใหญ่เป็นเกษตรกรรายย่อยที่เผชิญกับปัญหา **สภาวะความเครียดจากความร้อน (Heat Stress)** เนื่องจากสภาพอากาศร้อนชื้นและโครงสร้างโรงเรือนที่ระบายความร้อนได้จำกัด ส่งผลให้:
* **ผลผลิตน้ำนมและอัตราผสมติดลดลง (Boonkum et al., 2011; 2024):** โคนมลูกผสมไทยเริ่มได้รับผลกระทบเมื่อดัชนีความร้อน ($\text{THI}$) เฉลี่ยรายวันถึงเกณฑ์ **74–76** และผลผลิตลดลงเร็วขึ้นเมื่อ $\text{THI} \ge 82$
* **ความร้อนสะสมและการพักฟื้นในเวลากลางคืน (Igono et al., 1992):** หากโคนมเผชิญความร้อนต่อเนื่องหลายวันโดยที่เวลากลางคืน (22:00–06:00 น.) อากาศไม่เย็นลงต่ำกว่าเกณฑ์เฝ้าระวัง $\text{THI } 74$ ของระบบ แม่โคจะระบายความร้อนสะสมออกจากตัวได้ยาก (ค่า 74 เป็นเกณฑ์ของระบบ ไม่ใช่ค่าจาก Igono)
* **ข้อจำกัดของการพ่นหมอกในอากาศชื้น ($\text{RH} \ge 75\%$):** ในสภาพอากาศชื้นสูง การพ่นหมอกละอองฝอยทำให้อากาศอิ่มตัวแต่ไม่ช่วยลดอุณหภูมิ จึงควรเปลี่ยนไปใช้ **การฉีดน้ำเม็ดใหญ่ให้ตัววัวเปียกเป็นช่วงสั้นๆ ร่วมกับเปิดพัดลมแรง** แทน (Penn State Extension)

## 🔌 3. รายละเอียดอุปกรณ์ฮาร์ดแวร์ในระบบ (Hardware Specifications)

### 3.1 กล่องตรวจวัดสภาพแวดล้อม (ESP32-S3 Sensor Box — Firmware v1.6.1)
* **ไมโครคอนโทรลเลอร์:** ESP32-S3 เชื่อมต่อ Wi-Fi ส่งข้อมูลแบบ **HTTPS ที่ตรวจใบรับรองจริง (Root CA)** และบังคับใช้ **`X-Device-Key`** (อุปกรณ์ที่ไม่มีคีย์ไม่สามารถส่งข้อมูลเข้าระบบได้)
* **หัววัดอุณหภูมิ-ความชื้น:** **Sensirion SHT40** ต่อ I2C (SDA = GPIO11, SCL = GPIO12, ไฟ 3.3 V) ความแม่นยำตามสเปก $\pm 0.2^\circ\text{C}$ / $\pm 1.8\%\text{ RH}$ · firmware ตรวจรุ่นชิปจริงตอนบูต (SHT4x/SHT3x/AHT/HTU21) แล้วรายงานรุ่นและ serial ขึ้น heartbeat (บอร์ดทดสอบตรวจพบ `sht4x` ที่ 0x44) · มี **heater ในชิป** ไล่ไอน้ำเมื่อ RH ≥ 95% นาน 10 นาที · มี watchdog และกู้ Wi-Fi/รีบูตเองเมื่อ server ไม่ตอบ 15/30 นาที (หัววัดเดิม XY-MD02 เสียแล้ว จึงเปลี่ยนมาใช้ SHT40)
* **ระบบสำรองข้อมูลเมื่อเน็ตหลุด (Store-and-Forward):** เก็บข้อมูลลงไฟล์ `/q.bin` บนหน่วยความจำแฟลช LittleFS ในบอร์ด (สูงสุด 2 MB) พร้อมประทับเวลาจริงจาก NTP (`time.navy.mi.th`) เมื่ออินเทอร์เน็ตกลับมาจะทยอยส่งข้อมูลย้อนหลังเข้าเซิร์ฟเวอร์โดยไม่ซ้ำ
* **ระบบรายงานสุขภาพกล่อง (Heartbeat ทุก 5 นาที):** แยกสถานะได้ชัดเจนระหว่าง **ปกติ (`ok`)**, **เซ็นเซอร์เสีย/สายหลุด (`sensor_fault`)**, **มีข้อมูลค้างส่ง (`backlog`)**, และ **ออฟไลน์ (`offline`)** รวมถึงแจ้งเตือนเมื่อบอร์ดรีเซ็ตจากไฟตก (`brownout`)

### 3.2 กล้องวงจรปิด (Dahua Starlight Network Camera)
* **รุ่น:** `Dahua DH-IPC-HFW2231TP-ZAS-S2` (2MP Full HD 1080p, เซ็นเซอร์ 1/2.8" CMOS Starlight, เลนส์ซูมไฟฟ้า 2.7mm–13.5mm, มาตรฐานกันน้ำกันฝุ่น IP67)
* **การดึงภาพและรักษาความปลอดภัย:** บอร์ด ESP32-S3 ดึงภาพนิ่งจากกล้องตามรอบที่ตั้ง (15–60 วิ) ผ่าน HTTP Digest Authentication ในวงแลนเดียวกัน แล้วส่งขึ้นเซิร์ฟเวอร์ ส่วนรหัสผ่านกล้องในฐานข้อมูลถูกเข้ารหัสด้วย **AES-256-GCM** และไม่เก็บรหัสผ่านไว้ในลิงก์ RTSP

## 🧮 4. สูตรการคำนวณและเกณฑ์โคนมลูกผสมไทย (Single Source of Truth)

ระบบรวมศูนย์การคำนวณทั้งหมดไว้ที่ `heatStress.js`, `heatMetrics.js`, `forecastService.js` และ `outdoorWeather.js` เพื่อให้หน้าเกษตรกร หน้าแอดมิน รายงานสรุปรายวัน และสมุดสหกรณ์แสดงตัวเลขตรงกัน 100%:

1. **สูตรดัชนีอุณหภูมิและความชื้น (NRC, 1971):**
   $$\text{THI} = (1.8 \times T + 32) - (0.55 - 0.0055 \times \text{RH}) \times (1.8 \times T - 26)$$
   *วัดค่า $T$ ($^\circ\text{C}$) และ $\text{RH}$ ($\%$) ในโรงเรือนด้วยเซ็นเซอร์ของฟาร์ม โดยใช้สูตร NRC (1971) ตัวเดียวกับงานวิจัยโคนมไทย (Sae-tiao et al., 2019) และปรับใช้ที่ "ค่าเกณฑ์" ของโคนมลูกผสมไทย*

2. **เกณฑ์ระดับความเครียดความร้อนสำหรับโคนมลูกผสมไทย (Boonkum et al., 2011; 2024):**
   * **ปกติ (`normal`):** $\text{THI} < 74$
   * **เฝ้าระวัง (`mild`):** $74 \le \text{THI} < 76$ *(จุดที่น้ำนมเริ่มลดในแม่โคสายเลือดโฮลสไตน์สูง $\ge 87.5\%$ ท้องที่ 3 ขึ้นไป — Boonkum et al., 2011)*
   * **เครียดจากความร้อน (`moderate`):** $76 \le \text{THI} < 82$ *(เกณฑ์จุดเริ่มเครียดระดับประชากรโคนมลูกผสมไทย — Boonkum et al., 2024)*
   * **วิกฤต (`severe`):** $\text{THI} \ge 82$ *(จุดที่ผลผลิตน้ำนมลดลงเร็วขึ้นชัดเจน — Boonkum et al., 2011)*

3. **วิธีคำนวณตัวชี้วัดรายวันและรายชั่วโมง (5-Minute Bucketed Aggregation):**
   * **การแบ่งถังเวลา 5 นาที:** นำค่าเซ็นเซอร์มาเฉลี่ยทุก 5 นาที แล้วคำนวณ $\text{THI}$ ในแต่ละถัง โดยไม่เดาค่าในช่วงที่ไม่มีข้อมูล
   * **ความครบถ้วนของข้อมูล (`coverage_pct`):** $\text{ชั่วโมงที่มีข้อมูลจริง} \div \text{ชั่วโมงทั้งหมดในช่วงที่สรุป} \times 100\%$
   * **ชั่วโมงเครียด (`stress_hours`):** จำนวนถัง 5 นาทีที่มี $\text{THI} \ge 76$ คูณด้วย $\frac{5}{60}$ ชั่วโมง
   * **ระดับความเสี่ยงรายวัน (`daily_mean_level`):** ประเมินจาก **ค่าเฉลี่ย $\text{THI}$ ทั้งวัน** เพื่อเทียบตามวิธีของงานวิจัย
   * **ชั่วโมงกลางคืนที่วัวได้พัก (`night_relief_hours`):** จำนวนชั่วโมงในช่วง **22:00–06:00 น.** ที่ $\text{THI} < 74$
   * **จำนวนวันเครียดติดต่อกัน (`stressStreak`):** จำนวนวันล่าสุดที่ $\text{THI}$ เฉลี่ยรายวัน $\ge 76$ ติดต่อกัน (นับเฉพาะวันที่มีข้อมูลอย่างน้อย 12 ชั่วโมง)

4. **การเปรียบเทียบอากาศในโรงเรือนกับภายนอก (`outdoorWeather.js`) และคำแนะนำตามบริบทฟาร์มไทย:**
   * เปรียบเทียบค่าเฉลี่ยรายชั่วโมงย้อนหลัง 72 ชั่วโมงในช่วงบ่าย (**12:00–16:59 น.**) ระหว่างเซ็นเซอร์ในโรงเรือนกับค่าจากโมเดลสภาพอากาศ Open-Meteo ณ พิกัดฟาร์ม โดยเผื่อความคลาดเคลื่อนของโมเดล $\pm 2^\circ\text{C}$
   * คำนวณ **ช่วงเวลาร้อนที่สุด (4 ชม.)** และ **ช่วงเวลาเย็นที่สุดสำหรับให้อาหาร (3 ชม.)** จากข้อมูลจริงของโรงเรือนนั้นย้อนหลัง 72 ชั่วโมง แทนการใช้เวลาตายตัว
   * เมื่อความชื้นสัมพัทธ์ $\text{RH} \ge 75\%$ แนะนำให้ **งดพ่นหมอกฝอย และใช้การฉีดน้ำราดตัววัวช่วงสั้นๆ ร่วมกับเปิดพัดลมแรง** แทน

## ⚠️ 6. ข้อจำกัดปัจจุบันและแผนงานระยะถัดไป (Limitations & Deferred Roadmap)

### ข้อจำกัดที่ต้องทราบในระยะปัจจุบัน
1. **สถานะการทดสอบ:** ระบบทั้งหมดผ่านการทดสอบการทำงานในบ้านแล้ว (SHT40 + firmware 1.6.x ทำงานบนโต๊ะ (รอบเซ็นเซอร์ 15 วิตามนาฬิกาคงที่ตั้งแต่ 1.6.1)) แต่ยังไม่ได้ติดตั้งในโรงเรือนจริง · กำหนดไปฟาร์ม **6–7 ธ.ค. 2569** · รายละเอียดแผนอยู่ที่ `docs/PROJECT_PLAN.md` และ `docs/HANDOFF.md`
2. **ความแม่นยำของเซ็นเซอร์:** ใช้ค่าความคลาดเคลื่อนตามสเปกโรงงานของชิป SHT40 ($\pm 0.2^\circ\text{C} / \pm 1.8\%\text{ RH}$) ยังไม่ได้เทียบกับเครื่องวัดอ้างอิง · มีเครื่องมือ `compare_sensor.js` พร้อมแล้ว จะวัดช่วงทดสอบ 24 ชม. ที่บ้าน (30 พ.ย.–3 ธ.ค.) และที่ฟาร์ม 6–7 ธ.ค.
3. **ความแม่นยำของระบบพยากรณ์ 3 วัน:** ตัวเลข $\text{MAE } 0.69 / 0.78 / 0.88$ วัดกับสถานีอุตุนิยมวิทยากลางแจ้งสนามบินเชียงใหม่ (WMO 48327) ส่วนความแม่นยำในโรงเรือนจริงจะต้องวัดซ้ำหลังติดตั้งอย่างน้อย 2 สัปดาห์
4. **ความแม่นยำของโมเดลกล้อง:** เทรนจากชุดภาพต่างประเทศ จึงต้องอาศัยระบบเก็บภาพรายชั่วโมงที่สร้างไว้เพื่อนำมานับเทียบและ Fine-tune ด้วยภาพโรงเรือนไทยจริง

### สิ่งที่ตกลงไว้ว่าจะทำในระยะถัดไป (หลังติดตั้งที่ฟาร์มจริง)
1. **วัดความแม่นยำของการพยากรณ์ THI ล่วงหน้า 3 วันในโรงเรือนจริง** (หลังติดตั้ง 2 สัปดาห์)
2. **หน้านับเทียบความแม่นยำของโมเดลกล้อง และหน้าวิเคราะห์ `% วัวนอน เทียบกับค่า THI`** (หลังจากติดตั้งและเก็บภาพได้ 2–3 สัปดาห์)
3. **ระบบแจ้งเตือนผ่าน LINE รายฟาร์ม** (ทำในงานแฮ็กกาธอน)
4. **การเชื่อมต่อ Google Gemini AI** เพื่อช่วยสรุปรายงาน
5. **ระบบสั่งเปิดพัดลมหรือระบบทำความเย็นอัตโนมัติ**
