1 Executive Overview & Design Intent

The public-facing pages/index.vue is the central digital gateway of CowCare AI. It serves as an Agritech Product Overview and Interactive THI Sandbox grounded in verified dairy science.

Core Focus: Supporting Thai smallholder dairy farms with continuous barn microclimate sensing (ESP32-S3 + SHT20), Thai-Holstein daily-mean THI thresholds (74 / 76 / 82), 3-day hybrid THI forecasting (Open-Meteo ECMWF + farm sensor bias), and non-invasive posture counting (YOLO26m ONNX).

3 Detailed Architecture of the 7 Key Sections

Section 1: Hero Section & Interactive Telemetry Sandbox

Arranged in an asymmetrical split grid (7 cols narrative : 5 cols interactive sandbox):

  • Value Proposition & Eyebrow: Presents the Thai-Holstein daily-mean THI thresholds (74 / 76 / 82) and continuous barn monitoring without daily manual data entry by farmers.
  • Direct Authentication Route: Primary CTA button routes securely to /login (protecting internal administrator portals), accompanied by a smooth-scroll simulator button.
  • Interactive NRC 1971 Simulator: Demonstrates the THI calculation using the standard NRC (1971) formula:
NRC (1971) Standard Temperature-Humidity Index Formula THI = (1.8 × T + 32) - (0.55 - 0.0055 × RH) × (1.8 × T - 26)

4 Sample Scenarios

  • Chiang Mai (Winter): 24.0°C, 55% RH → THI 70.8 (Normal < 74)
  • Watch Condition: 27.5°C, 65% RH → THI 75.1 (Mild 74–75.9)
  • Moderate Stress: 30.5°C, 65% RH → THI 79.6 (Moderate 76–81.9)
  • Severe Heat Stress: 34.0°C, 70% RH → THI 85.6 (Severe ≥ 82)

Humidity-Aware Cooling Advisory

Follows heatStress.js: when relative humidity RH ≥ 75%, advises avoiding fine misting and instead using brief direct cow wetting paired with fan airflow (Penn State Extension). Does not claim milk loss in kilograms.

Section 2: Scientific Signal Strip (Deep Green Banner #24433A)

A high-contrast four-column data banner highlighting the core methodology of CowCare AI:

  • THI 74 / 76 / 82: Daily-mean heat stress thresholds for Thai crossbred dairy cattle (Boonkum et al., 2011; 2024).
  • 22:00–06:00: Night relief window where THI < 74 allows cows to recover from daytime heat load (Igono et al., 1992).
  • 5-Min Buckets: Unified sensor aggregation interval without gap interpolation (heatMetrics.js).
  • 3-Day Forecast: Daily-mean THI forecast using Open-Meteo ECMWF + 3–14 day farm sensor median bias (forecastService.js).

Section 3: 3-Layer Architecture & Bento Feature Matrix

Visualizes the end-to-end data pipeline in three distinct cards:

  • Sense (Card 01 — Deep Forest #24433A): ESP32-S3 (v1.4.1) microcontroller with SHT20 (XY-MD02) temperature/humidity sensor over RS485 Modbus RTU (±0.3°C / ±3% RH, THI ±0.7) and Dahua IP camera snapshot every 10 minutes. Features the YOLO26m ONNX model (best.onnx) counting 4 bovine postures: drinking, feeding, lying down, and standing with Class-Agnostic NMS.
  • Recommend (Card 02 — Elevated Glass): 3-day hybrid THI forecast (hybrid-ecmwf-bias-v1: Open-Meteo ECMWF + 3–14 day farm sensor bias, backtested over 354 days at Chiang Mai airport station WMO 48327 with MAE 0.69 / 0.78 / 0.88) and farm-specific peak/cool windows.
  • Capitalize (Card 03 — Elevated Glass): Digital logbooks on PostgreSQL / Supabase reporting data completeness (coverage_pct), night relief hours, and consecutive stress days for cooperatives.

Section 4: 3-Day Hybrid Forecast & Thermal Accumulation Pipeline (#19362E)

Deep night-forest contrast section detailing the forecasting and early-warning pipeline:

3-Day Hybrid Forecast Pipeline (hybrid-ecmwf-bias-v1):
• Inputs: SHT20 Barn Telemetry (3–14 Completed Days) + Open-Meteo ECMWF Hourly Forecast at Farm Coordinates.
• Core Processing: Per-horizon (+1/+2/+3 d) median bias correction (clamped to ±6 THI) and 5-minute bucketed THI metrics.
• Outputs: 3-Day Daily-Mean THI Forecast, Farm-Specific Hottest/Coolest Windows, and Humidity-Aware Cooling Advice.

4 Security & Access Control Architecture

Zero Administrative Exposure on Public Surfaces:
In accordance with security standards, all direct references and navigation links to /Admin ("Command Center") have been stripped from the public landing page. All visitors authenticate through /login.
  • Layout Guard (frontend/app/layouts/admin.vue): Automatic verification of authentication token and role claims alongside backend verifyToken + requireRole('admin').
  • Admin-Only Registration: Account creation (POST /api/auth/register) requires an authenticated admin token.
