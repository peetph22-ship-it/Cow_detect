# CBVD-5 → YOLO (4 ท่า)

ที่มา: CBVD-5 (Cow Behavior Video Dataset), Kaggle `fandaoerji/cbvd-5cow-behavior-video-dataset`, License CC0
อ้างอิง: Li K., Fan D., Wu H., Zhao A. *A new dataset for video-based cow behavior recognition.* Sci Rep 14, 18702 (2024). doi:10.1038/s41598-024-65953-x

- ฟาร์มเดียว (มองโกเลียใน) วัวสาวอายุ 20 เดือน 107 ตัว กล้อง Dahua อินฟราเรด 7 ตัว ติดผนัง ก้ม 17° ภาพ 1920x1080 (ไม่ถูกยืด)
- ชุดข้อมูลฝึกเดิม (`cow-behavior-analysiws--2`, Roboflow) มีภาพ CBVD-5 อยู่แล้ว 969 ภาพ (ชื่อ `<คลิป>_<เฟรม>` ตรงกันทุกภาพ)
- `labelframes_add` (1,200 ภาพ) ไม่มีกรอบคำตอบ จึงไม่ได้ใช้

## วิธีสร้างใหม่
1. ดาวน์โหลด `annotations`, `labelframes` จาก Kaggle แตกไฟล์ไว้ที่ `raw/annotations`, `raw/labelframes`
2. `tools/cluster_cameras.py` จัดคลิปเป็นกลุ่มตามมุมกล้อง (พื้นหลังของกล้องติดตาย) ผลที่ใช้จริงอยู่ใน `tools/camera_groups.json`
   (4 มุม: ทางเดินรางอาหาร A 315 คลิป, B 272, ในคอก A 52, ในคอก B 48; กลุ่มเล็กถูกรวมเข้ากลุ่มที่คล้ายที่สุด)
3. `python tools/convert_cbvd5.py raw tools/camera_groups.json yolo 2`

## การแบ่งชุด (`yolo/split.json`)
- test = มุม "ในคอก A" ทั้งหมด (37 คลิป, 222 ภาพ) ไม่ใช้ฝึก
- val = 10% ของคลิปที่เหลือ (50 คลิป, 299 ภาพ), train = 450 คลิป, 2,678 ภาพ
- ภาพจากคลิปเดียวกันอยู่ชุดเดียวเสมอ (ชุดแบ่งของเปเปอร์สุ่มแล้วมี 50 คลิปปนหลายชุด)
- ถ้ารวมกับชุดเดิมเพื่อฝึก: ต้องตัดภาพของคลิปใน test ออกจากชุดเดิมด้วย (ชุดเดิมมี 68 ภาพจากคลิปเหล่านี้)

## แปลงท่า
CBVD-5 มีท่า (ยืน/นอน) + สถานะ (กิน/ดื่ม/เคี้ยวเอื้อง) ต่อวัว 1 ตัว → ดื่ม = drinking, กิน (foraging) = feeding, นอน = lying down, อื่นๆ = standing

## เทียบกรอบกับชุด Roboflow เดิม (969 ภาพเดียวกันทุกพิกเซล, 2026-11-20)
- นิยามท่าตรงกันเป็นส่วนใหญ่ (วัวตัวเดียวกัน IoU >= 0.3, 5,055 ตัว): นอน 98%, ยืน 86%, กิน 77%, ดื่ม 75%
  - ส่วนที่ไม่ตรงมากที่สุด: Roboflow เรียก "กิน" แต่ CBVD-5 เรียก "ยืน" 320 ตัว (วัวยืนที่รางแต่ไม่ได้ก้มกิน) ทำให้โมเดลปัจจุบันทาย feeding เกินบนชุดนี้
- คุณภาพกรอบต่างกันมาก: Roboflow กรอบหลวมกว่า มี 281 กรอบที่ครอบวัว 2 ตัวขึ้นไป และไม่มีกรอบให้วัวที่ CBVD-5 ตีไว้ 2,481 ตัว
  (วัว 6.4 vs 7.8 ตัว/ภาพ) วัวที่ไม่ถูกตีกรอบในภาพฝึกสอนให้โมเดลมองข้ามวัว จึงเป็นสาเหตุหนึ่งที่ recall ต่ำ
- ถ้ารวมชุด: ใช้กรอบของ CBVD-5 แทนกรอบ Roboflow สำหรับ 969 ภาพนี้ และสุ่มตรวจภาพ A04 อีก 908 ภาพของ Roboflow ก่อนใช้

## ผลโมเดลปัจจุบัน (yolo26m_480, stretch, conf 0.25) บนชุด test (154 ภาพที่ไม่อยู่ในชุดฝึกเดิม)
