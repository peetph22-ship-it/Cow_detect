# ทดสอบวิธีพยากรณ์ THI 3 วัน (ที่มาของตัวเลขใน forecastService.js)

เทียบวิธีพยากรณ์ THI เฉลี่ยรายวันล่วงหน้า +1/+2/+3 วัน กับค่าวัดจริงของสถานีอุตุฯ สนามบินเชียงใหม่ (WMO 48327)
ข้อมูลอยู่นอก repo ดาวน์โหลดใหม่ได้ด้วย `fetch_station_data.sh`

```sh
sh fetch_station_data.sh ~/cowcare_forecast_data
../../venv/bin/python -I verify_openmeteo.py ~/cowcare_forecast_data   # 3 แบบจำลอง + ปรับค่าเพี้ยนจาก N วัน
../../venv/bin/python -I eval_strict.py ~/cowcare_forecast_data        # แบบเข้มงวด + GRU + ค่าเพี้ยนพื้นที่
```

ผลหลัก (eval_strict.py, ทดสอบ 2024-12-19..2025-12-07 (354 วันที่มีข้อมูลครบ), MAE ของ THI เฉลี่ยรายวัน):

| วิธี | +1 | +2 | +3 |
|---|---|---|---|
| เดิม: ค่าเฉลี่ย 72 ชม. | 1.10 | 1.38 | 1.56 |
| ECMWF ดิบ | 1.34 | 1.32 | 1.35 |
| ECMWF + ค่าเพี้ยน 14 วันล่าสุด (ใช้จริง, วันทดสอบมีประวัติ ≥ 9 วัน) | 0.69 | 0.78 | 0.88 |
| ECMWF + ค่าเพี้ยน 3 วันล่าสุด | 0.80 | 0.92 | 1.07 |
| ECMWF + ค่าเพี้ยนเฉลี่ยพื้นที่ (ช่วงเทรน 2024) | 0.77 | 0.83 | 0.90 |
| GRU 1,212 ค่า (เฉลี่ย 3 seed) | 0.88 | 0.91 | 0.91 |

ข้อจำกัด
- สถานีอยู่กลางแจ้ง ไม่ใช่โรงเรือน ความแม่นในโรงเรือนต้องวัดซ้ำหลังติดตั้ง
- ข้อมูลเทียบมีประมาณ 2 ปี (2024–2025)
- `home_check.py` ลองกับเซ็นเซอร์ทดสอบในบ้าน แต่มีวันที่ข้อมูลครบแค่ 6 วันไม่ต่อเนื่อง จึงยังวัดผลไม่ได้
- Historical Forecast API ของ Open-Meteo ไม่ใช่พยากรณ์ล่วงหน้า 3 วันจริง จึงใช้ Previous Runs API (`*_previous_dayN`)
- การวัดใช้ `*_previous_dayK` ทั้งหมด แต่ระบบจริงทายวัน +k ด้วยค่ารอบล่าสุด ซึ่งระยะพยากรณ์สั้นกว่าเล็กน้อย
  ค่าเพี้ยนแทบไม่ขึ้นกับระยะ (-1.41/-1.37/-1.32) ผลกระทบจึงเล็ก แต่ตัวเลขไม่ได้วัดจากรอบล่าสุดโดยตรง
- ระบบจริงใช้มัธยฐานของค่าเพี้ยน (ทนวันที่เซ็นเซอร์ผิดปกติ) ส่วนการทดสอบใช้ค่าเฉลี่ย
