Project Roadmap - CowCare AI
CowCare AI -- PROJECT ROADMAP
แผนการดำเนินการโครงการ (ฉบับปรับปรุงตามสถานะปัจจุบัน)
หลักการสำคัญ
1.	ข้อมูลคือทรัพยากรที่ซื้อไม่ได้ -- ต้องเริ่มเก็บข้อมูลทันที
2.	แยกงานขวางทาง (Blocking) ออกจากงานเสริมความงาม
3.	ทำ Pipeline ให้ครบวงจรก่อน แล้วค่อยปรับปรุงคุณภาพ
PHASE 0: เตรียมการระหว่างรอฮาร์ดแวร์ (ทำได้ทันที)
●	ออกแบบ Database Schema และตรวจสอบการรองรับ TimescaleDB บน Supabase
●	สร้าง Mock Data Generator สำหรับทดสอบระบบ
●	ดึงข้อมูลอุตุนิยมวิทยาย้อนหลัง 5-10 ปี เพื่อ pre-train LSTM แก้ปัญหา Cold Start
●	เตรียม Dataset สำหรับ YOLO (รวมภาพกลางคืน)
●	สำรวจฟาร์มเป้าหมายและขอข้อมูลผลผลิตน้ำนมย้อนหลัง
PHASE 1: ทำ Data Pipeline ให้ครบวงจร (วิกฤตที่สุด)
●	พัฒนา Firmware ESP32-S3 ใช้ MQTT แทน HTTP POST พร้อมระบบ Store-and-Forward ลง SD Card/SPIFFS กันข้อมูลหายตอนเน็ตหลุด
●	ติดตั้งเซนเซอร์คู่ ใน-นอกโรงเรือน ที่ระดับหัวโค (1.2-1.5 เมตร) เพื่อคำนวณ Barn Penalty
●	พัฒนา Endpoint และ MQTT subscriber ฝั่ง Node.js
●	ระบบตรวจสอบสุขภาพข้อมูล (Data Health Monitoring)
PHASE 2: Computer Vision + กล้อง Hikvision
●	ตั้งค่ากล้อง Hikvision ใช้ Sub Stream (/102) สำหรับ YOLO เพื่อประหยัดซีพียู พร้อมตั้งค่าความปลอดภัย (เปลี่ยนรหัสผ่าน, ห้าม port forward 554 ตรง, ใช้ VPN)
●	กำหนด Class YOLO ที่ทำได้จริง (standing, lying, at water, open mouth) และคำนวณตัวชี้วัดระดับฝูง (standing ratio, bunching index)
●	ปรับ YOLO เป็น Scheduled Inference (ทุก 5 นาที)
PHASE 3: โมเดลทำนาย LSTM
●	กำหนด Target Variable เป็นการทำนายปริมาณน้ำนมหรือระดับความเครียดล่วงหน้า 3-7 วัน (ห้ามทำนาย THI จาก Temp/RH ในวันเดียวกันเพื่อป้องกัน circular prediction)
●	Feature Engineering ตามหลักฐานวิจัย (THI rolling 5d, nocturnal recovery, barn penalty, RH separate)
●	เปรียบเทียบกับ Baseline ครบถ้วน (Persistence, ARIMA, Random Forest, LSTM)
●	วิเคราะห์ SHAP Feature Importance ตรวจสอบบทบาทของความชื้น
PHASE 4: Dashboard + ระบบแจ้งเตือน
●	พัฒนา Dashboard ด้วย Nuxt + Vuetify ออกแบบตามหลักการสำหรับผู้สูงวัย (หน้าแรกตอบคำถามเดียว, ระบบไฟจราจร)
●	ระบบ Auth (JWT) และเปิด Row Level Security บน Supabase
●	เชื่อมต่อ Gemini API สร้างคำแนะนำสั้น กระชับ ตรงบริบทฟาร์ม (พร้อม Hard rule ห้ามพ่นหมอกตอนความชื้นสูง)
●	เชื่อมต่อ LINE Messaging API ส่ง Flex Message แบบจำกัดความถี่เพื่อป้องกัน Alert Fatigue
PHASE 5: Validation + งานวิชาการ
●	Field Validation ต่อเนื่อง 3-6 เดือนในฟาร์มจริง
●	เก็บ Ground Truth ทางสรีรวิทยา (วัดคอร์ติซอลจากมูลร่วมกับสัตวศาสตร์)
●	วิเคราะห์ Cost-Benefit และระยะเวลาคืนทุน
●	ตรวจสอบตัวเลขอ้างอิงทั้งหมดในเอกสารก่อนนำเสนอ
