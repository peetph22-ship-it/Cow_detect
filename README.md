## 📌 1. ที่มาและความสำคัญของโครงการ (Problem & Core Approach)

เกษตรกรผู้เลี้ยงโคนมในประเทศไทยส่วนใหญ่เป็นฟาร์มรายย่อยที่เผชิญปัญหา **สภาวะความเครียดจากความร้อน (Heat Stress)** จากสภาพอากาศร้อนชื้นและโครงสร้างโรงเรือนที่ระบายอากาศได้จำกัด:

1. **เกณฑ์ความเครียดความร้อนของโคนมลูกผสมไทย (Boonkum et al., 2011; 2024):**
   โคนมลูกผสมโฮลสไตน์ในประเทศไทยเริ่มได้รับผลกระทบต่อผลผลิตน้ำนมเมื่อดัชนีอุณหภูมิและความชื้น ($\text{THI}$) เฉลี่ยรายวันถึงเกณฑ์ **74** (ในแม่โคสายเลือดโฮลสไตน์สูง $\ge 87.5\%$ ท้องที่ 3 ขึ้นไป) มีเกณฑ์จุดเริ่มเครียดระดับประชากรที่ **76** และผลผลิตน้ำนมลดลงเร็วขึ้นชัดเจนเมื่อ $\text{THI} \ge 82$
2. **การพักฟื้นจากความร้อนในเวลากลางคืน (Igono et al., 1992):**
   หากโคนมเผชิญความร้อนสะสมต่อเนื่องในตอนกลางวัน และช่วงกลางคืน (22:00–06:00 น.) ค่า $\text{THI}$ ในโรงเรือนไม่ลดต่ำกว่า **74** (เกณฑ์เฝ้าระวังของระบบสำหรับโคลูกผสมไทย ไม่ใช่ค่าจาก Igono ซึ่งศึกษาโฮลสไตน์ในเขตทะเลทราย) แม่โคจะระบายความร้อนสะสมออกจากตัวได้ยาก
3. **ข้อจำกัดของการพ่นหมอกในสภาพอากาศชื้น ($\text{RH} \ge 75\%$):**
   เมื่อความชื้นสัมพัทธ์สูง การพ่นหมอกละอองฝอยทำให้อากาศอิ่มตัวแต่ไม่ช่วยลดอุณหภูมิ จึงควรเปลี่ยนไปใช้ **การฉีดน้ำเม็ดใหญ่ให้ตัววัวเปียกช่วงสั้นๆ ร่วมกับเปิดพัดลมแรง** แทน (Penn State Extension)
4. **หลักการออกแบบสำหรับเกษตรกรรายย่อย:**
   **เกษตรกรไม่ต้องกรอกข้อมูลรายวัน** ระบบใช้กล่องเซ็นเซอร์และกล้องทำงานอัตโนมัติ พร้อมเช็กลิสต์การดูแลแบบแตะเลือกและปุ่มโทรหาสัตวแพทย์ประจำฟาร์ม

## 🧮 3. สูตรการคำนวณและเกณฑ์โคนมลูกผสมไทย (`heatStress.js`, `heatMetrics.js`)

การคำนวณความร้อนทั้งหมดรวมศูนย์อยู่ที่ฝั่ง Backend (`backend_node/app/services/heatStress.js` และ `heatMetrics.js`) ไม่คำนวณซ้ำในหน้าเว็บ เพื่อให้ตัวเลขตรงกันทุกหน้า:

### 3.1 สมการดัชนีอุณหภูมิและความชื้น (NRC, 1971)
ใช้สมการ **NRC (1971)** ตัวเดียวกับที่งานวิจัยโคนมไทยใช้ (Sae-tiao et al., 2019):

$$\text{THI} = (1.8 \times T + 32) - (0.55 - 0.0055 \times \text{RH}) \times (1.8 \times T - 26)$$

* $T$ = อุณหภูมิภายในโรงเรือน ($^\circ\text{C}$) จากเซ็นเซอร์ SHT20 (XY-MD02, สเปก $\pm 0.3^\circ\text{C}$)
* $\text{RH}$ = ความชื้นสัมพัทธ์ภายในโรงเรือน ($\%$) จากเซ็นเซอร์ SHT20 (สเปก $\pm 3\%\text{ RH}$, คิดเป็นความคลาดเคลื่อนตามสเปก $\text{THI} \approx \pm 0.7$)

### 3.2 เกณฑ์ระดับความเครียดความร้อนจาก THI เฉลี่ยรายวัน (Boonkum et al., 2011; 2024)

| ระดับความเสี่ยง (`riskLevel`) | เกณฑ์โคนมลูกผสมไทยทั่วไป (`default`) | เกณฑ์ฝูงสายเลือด HF สูง $\ge 87.5\%$ (`high_hf`) | ความหมายและที่มาทางวิชาการ |
| :--- | :---: | :---: | :--- |
| 🟢 **ปกติ (`normal`)** | $\text{THI} < 74$ | $\text{THI} < 72$ | สภาวะปกติ โคระบายความร้อนได้ตามปกติ |
| 🟡 **เฝ้าระวัง (`mild`)** | $74 \le \text{THI} < 76$ | $72 \le \text{THI} < 74$ | น้ำนมเริ่มลดในแม่โคท้องที่ 3 ขึ้นไป สายเลือด HF $\ge 87.5\%$ (Boonkum et al., 2011) |
| 🟠 **เครียดจากความร้อน (`moderate`)** | $76 \le \text{THI} < 82$ | $74 \le \text{THI} < 80$ | เกณฑ์จุดเริ่มเครียดระดับประชากรโคนมลูกผสมไทย (Boonkum et al., 2024) |
| 🔴 **วิกฤต (`severe`)** | $\text{THI} \ge 82$ | $\text{THI} \ge 80$ | ผลผลิตน้ำนมลดลงเร็วขึ้นชัดเจน ต้องเร่งระบายความร้อน (Boonkum et al., 2011) |

### 3.3 วิธีคำนวณตัวชี้วัดแบบแบ่งถังเวลา 5 นาที (`heatMetrics.js`)
* **ถังเวลา 5 นาที:** เฉลี่ยค่าเซ็นเซอร์ทุก 5 นาที แล้วคำนวณ $\text{THI}$ โดยไม่เดาค่าในช่วงที่ไม่มีข้อมูล
* **ความครบถ้วนของข้อมูล (`coverage_pct`):** ชั่วโมงที่มีข้อมูลจริง $\div$ ชั่วโมงทั้งหมดในช่วงที่สรุป $\times 100\%$
* **ชั่วโมงเครียด (`stress_hours`):** จำนวนช่วง 5 นาทีที่มี $\text{THI} \ge 76$ คูณด้วย $\frac{5}{60}$ ชั่วโมง
* **ชั่วโมงกลางคืนที่ได้พัก (`night_relief_hours`):** จำนวนชั่วโมงในช่วง **22:00–06:00 น.** ที่ $\text{THI} < 74$ (เกณฑ์เฝ้าระวัง 74 ของระบบสำหรับโคลูกผสมไทย; แนวคิดว่าความเย็นกลางคืนช่วยให้โคฟื้นตัวมาจาก Igono et al., 1992 ซึ่งศึกษาโฮลสไตน์ในเขตทะเลทราย ไม่ได้กำหนดค่า 74)
* **จำนวนวันเครียดติดต่อกัน (`stressStreak`):** จำนวนวันล่าสุดที่ $\text{THI}$ เฉลี่ยรายวัน $\ge 76$ ติดต่อกัน (นับเฉพาะวันที่มีข้อมูลอย่างน้อย 12 ชั่วโมง)

## 📈 4. ระบบพยากรณ์ THI ล่วงหน้า 3 วัน (`forecastService.js`, `hybrid-ecmwf-bias-v1`)

ระบบพยากรณ์ค่า $\text{THI}$ เฉลี่ยรายวันล่วงหน้า +1, +2 และ +3 วัน โดยใช้พยากรณ์อากาศรายชั่วโมงจาก **Open-Meteo ECMWF (`ecmwf_ifs025`)** ณ พิกัดฟาร์ม ร่วมกับการปรับค่าเพี้ยนมัธยฐาน (median bias) ที่คำนวณจากเซ็นเซอร์จริงของฟาร์มในช่วง **3–14 วันที่ผ่านมา** (เฉพาะวันที่ข้อมูลครบ $\ge 20$ ชม. และช่วงกลางวัน 10:00–17:00 น. ขาดไม่เกิน 1 ชม. จำกัดค่าปรับไม่เกิน $\pm 6\text{ THI}$):

* **กรณีฟาร์มมีข้อมูลไม่ถึง 3 วัน:** หากใช้โมเดล ECMWF ในจังหวัดภาคเหนือ จะใช้ค่าเพี้ยนระดับภูมิภาคจากสถานีสนามบินเชียงใหม่ (`-1.41 / -1.37 / -1.32` สำหรับ +1/+2/+3 วัน)
* **กรณีสำรอง (Fallback):** หาก ECMWF ขัดข้องจะถอยกลับไปใช้ `best_match` และหากไม่มีพิกัดฟาร์มหรือเรียก API ไม่สำเร็จจะใช้ค่าเฉลี่ย 72 ชั่วโมงย้อนหลัง (`baseline_72h_mean`) พร้อมแจ้งสาเหตุใน `fallback_reason`

### ผลการทดสอบย้อนหลัง (Backtest) กับสถานีสนามบินเชียงใหม่ (WMO 48327)
ทดสอบกับข้อมูลจริงสถานีอุตุนิยมวิทยาสนามบินเชียงใหม่ (WMO 48327) จำนวน **354 วัน** (19 ธ.ค. 2024 – 7 ธ.ค. 2025) วัดค่าความคลาดเคลื่อนเฉลี่ยสัมบูรณ์ (MAE) ของ $\text{THI}$ เฉลี่ยรายวัน (ดูสคริปต์และรายละเอียดใน [`backend/ml_lstm/forecast_eval/README.md`](file:///Users/phattaradanai/Desktop/testYOLO26/backend/ml_lstm/forecast_eval/README.md)):

| วิธีพยากรณ์ | MAE +1 วัน | MAE +2 วัน | MAE +3 วัน | หมายเหตุ |
| :--- | :---: | :---: | :---: | :--- |
| **ค่าเฉลี่ย 72 ชม. ย้อนหลัง (`baseline_72h_mean`)** | 1.10 | 1.38 | 1.56 | ใช้ค่าเดิมซ้ำทั้ง 3 วัน |
| **ECMWF ดิบ (ไม่ปรับค่าเพี้ยน)** | 1.34 | 1.32 | 1.35 | มีความต่างระดับพื้นที่/ความชื้น |
| **ECMWF + ปรับค่าเพี้ยน 14 วัน (`hybrid-ecmwf-bias-v1`)** | **0.69** | **0.78** | **0.88** | เฉพาะวันทดสอบที่มีประวัติครบ $\ge 9$ วัน; ระดับความเสี่ยงตรง **94% / 93% / 92%** |
| **ECMWF + ปรับค่าเพี้ยน 3 วัน** | 0.80 | 0.92 | 1.07 | กรณีเพิ่งติดตั้งมีข้อมูลครบ 3–8 วัน |
| **ECMWF + ค่าเพี้ยนคงที่จากปี 2024 (`regional_bias`)** | 0.77 | 0.83 | 0.90 | ใช้เมื่อฟาร์มภาคเหนือมีข้อมูลไม่ถึง 3 วัน |

## 🎥 5. ระบบกล้องและ Computer Vision (`visionService.js`, `visionPostprocess.js`)

* **โมเดลที่ใช้งานจริง:** `YOLO26m ONNX` (`best.onnx`) รันบน Node.js Worker Thread ใน `backend_node` (ไม่มีระบบติดตามตัววัว ByteTrack และไม่ตรวจจับท่าหอบ)
* **4 ท่าทางที่ตรวจจับ (`CLASS_NAMES`):**
  1. `drinking` (ดื่มน้ำ)
  2. `feeding` (กินอาหาร)
  3. `lying down` (นอนพัก)
  4. `standing` (ยืน)
* **Class-Agnostic NMS (`conf = 0.25`, `iouThr = 0.70`, `agnostic = true`):** ตัดกรอบซ้อนโดยไม่ดูท่า (บังคับวัว 1 ตัว = 1 กรอบ)
* **ผลการทดสอบบนชุดภาพทดสอบ 203 ภาพและข้อจำกัด:**
